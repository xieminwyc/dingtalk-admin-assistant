# 万事通首页交互深度优化 v1.1 设计规范

> 日期：2026-03-31  
> 版本：v1.1（优化迭代，基于 v1.0 MVP 的交互升级）  
> 范围：首页卡片交互革新、沉浸模式面板、示例问题行为变更、动态 placeholder、思考态加强  
> 目标：从"点卡片聚焦输入框"升级为"点卡片变身场景化工作台"

---

## 1. 迭代背景与核心痛点

v1.0 MVP 已完成首页门户骨架，但存在以下体验短板：

| 痛点 | 说明 |
|------|------|
| 卡片点击感不强 | 每张卡有独立的"使用"按钮，点击后只聚焦输入框，缺乏"场景感" |
| 示例问题直接发送 | 用户点击示例后直接发送，没有修改机会，认知负荷大 |
| placeholder 静态 | 所有模式下输入框 placeholder 相同，模式感弱 |
| 思考态视觉轻量 | "AI 正在思考..." 气泡平淡，不支持禁用输入 |
| 无场景化面板 | 进入"找制度"等模式后，没有额外提示或快捷操作 |

---

## 2. 核心交互革新：从"聚焦输入"到"场景变身"

### 2.1 原有逻辑（v1.0）

```
点击"使用"按钮 → setActiveEntryMode + focusComposer
点击示例问题   → 直接 sendMessage
```

### 2.2 优化后逻辑（v1.1）

```
点击整张卡片   → setActiveEntryMode + focusComposer + 展示场景面板
点击示例问题   → 填入输入框（可编辑）+ 聚焦，不自动发送
```

---

## 3. 具体交互变更

### 3.1 移除"使用"按钮，整张卡片可点击

- 移除每张卡右上角的"使用"胶囊按钮
- 整个卡片区域（title/description/helper）点击后激活该模式
- 保留示例问题作为独立可点击元素（行为改变见 3.2）
- 激活态卡片加深边框 + 轻浮起阴影

### 3.2 示例问题：填入不发送

**变更前：** 点击 → `sendMessage(exampleQuestion, entryMode)`  
**变更后：** 点击 → `setDraft(exampleQuestion)` + `setActiveEntryMode(entryMode)` + `focusComposer()`

用户看到文字移入输入框，可修改后再发送，降低误操作，提升理解深度。

### 3.3 动态 placeholder

根据 `activeEntryMode` 实时更新输入框 placeholder：

| entryMode | placeholder 文案 |
|-----------|-----------------|
| `null`（默认）| `输入你想问的问题，或让我帮你写点什么` |
| `knowledge` | `请输入制度名、政策关键词，AI 为你深度解读...` |
| `contact` | `请输入业务场景或问题，AI 帮你找到对接人...` |
| `task` | `请描述你要办的事，AI 为你找到办理入口...` |
| `writing` | `请告诉我你要写的文章类型、主题、字数...` |
| `image_placeholder` | `描述你想生成的画面：风格、场景、主体...` |

### 3.4 场景面板（Mode Panel）

点击卡片激活模式后，在卡片区域与输入区之间插入一个**场景面板**，提供模式专属的快捷操作：

**找制度（knowledge）：**
- 快捷标签：`考勤` `请假` `年终奖` `绩效` `福利`
- 点击标签 → 预填 `{标签}相关制度是什么？` 到输入框

**找对接人（contact）：**
- 快捷标签：`PMS制卡` `人力资源` `OA流程` `IT支持`
- 点击标签 → 预填 `{标签}应该找谁？` 到输入框

**找流程（task）：**
- 快捷标签：`请假` `报销` `权限申请` `慧管家`
- 点击标签 → 预填 `怎么{标签}？` 到输入框

**帮我写作（writing）：**
- 快捷模板：`周报` `方案` `通知` `总结`
- 点击模板 → 预填 `帮我写一份{模板}` 到输入框

**图片生成（image_placeholder）：**
- 提示文案：`🖼️ 图片生成能力即将上线，你可以先描述你的想法`

### 3.5 思考态加强

发送消息后：

1. 立即禁用输入框和发送按钮（`disabled`）
2. "AI 正在思考..." 气泡改为带打点动画（CSS animation）
3. 接口返回后，恢复输入，替换气泡内容

## 4. 卡片视觉优化

### 4.1 Hover 效果

```css
.portal-entry-card {
  cursor: pointer;
  transition: transform 0.15s ease, box-shadow 0.15s ease, border-color 0.15s ease;

.portal-entry-card:hover {
  transform: translateY(-2px);
  box-shadow: 0 20px 48px rgba(37, 99, 235, 0.12);
  border-color: rgba(37, 99, 235, 0.25);
}
```

## 6. 验收标准

1. 首页卡片无"使用"按钮，整张卡片可点击激活
2. 点击卡片后，在卡片区与输入区之间出现场景面板（含快捷标签）
3. 点击快捷标签或示例问题，文字进入输入框，不自动发送
4. 输入框 placeholder 随 activeEntryMode 动态切换
5. 卡片有 hover 浮起效果，激活态有蓝色边框 + 浅蓝背景
6. 发送中输入框和按钮禁用，"AI 正在思考..."有打点动画
7. 接口返回后气泡内容替换，输入恢复可用
