# 非业务合同管理制度

发布日期：2025/7/16  
生效日期：2025/7/16

## 合同分类与范围

### 涵盖类型
涵盖品宣、运维、行政（场地/后勤）、采购（非销售类）、人力资源、财务、研发等非业务合同。

### 不适用范围
销售合同按《销售合同管理细则》执行，不适用本制度。

## 审批与分级

### 分级标准
小额合同（2 万元以下）走常规审批流程：部门初审 -> 专业评估 -> 法务 -> 财务 -> 分管负责人 -> CEO。  
大额合同（2 万元以上）必须由董事长最终审批。

### 时效要求
提请人应提前 72 小时发起申请。  
每个审批节点的审批限时为 24 小时。
