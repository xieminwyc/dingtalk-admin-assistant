## 基础信息

- **Base URL**: `http://192.168.30.68:13718`（开发环境）
- **Content-Type**: `application/json; charset=utf-8`
- **鉴权**: 若服务配置了 `API_KEYS`，所有业务接口需携带 `Authorization: Bearer <key>`

---

## 通用错误响应

```json
{
  "error": "错误描述信息"
}
```

常用 HTTP 状态码：

- `200` - 成功
- `202` - 任务已接受（异步处理）
- `400` - 请求参数错误
- `401` - API Key 无效或缺失
- `404` - 资源不存在
- `409` - 状态冲突
- `500` - 服务器内部错误
- `503` - 服务未就绪

## 1. 健康检查接口

### 1.1 基本健康检查

**GET** `/healthz`

检查服务基本存活状态。无需鉴权。

```bash
curl http://192.168.30.68:13718/healthz

```

**响应**：

```json
{ "status": "ok" }
```

---

### 1.2 就绪检查

**GET** `/readyz`

检查服务所有依赖（数据库、索引）是否就绪。无需鉴权。

```bash
curl http://192.168.30.68:13718/readyz

```

**响应**（成功）：

```json
{
  "status": "ok",
  "checks": [{ "name": "db", "status": "ok" }]
}
```

**响应**（失败，HTTP 503）：

```json
{
  "status": "fail",
  "checks": [{ "name": "db", "status": "fail", "error": "connection timeout" }]
}
```

## 2. 知识库查询接口

### 2.1 搜索知识库

**POST** `/api/v1/knowledge/search`

跨文档搜索相关的 chunk 段，结果经钉钉实时 ACL 过滤。

**字段说明**：

| 字段          | 类型   | 必填 | 说明                                   |
| ------------- | ------ | ---- | -------------------------------------- |
| `query`       | string | 是   | 搜索查询文本                           |
| `operatorId`  | string | 是   | 操作者 unionId（用于 ACL 过滤和审计）  |
| `workspaceId` | string | 否   | 限定 workspace，不填则跨所有 workspace |
| `maxResults`  | int    | 否   | 返回数量，默认 10，上限 50             |
| `directoryId` | string | 否   | 限定目录范围                           |
| `nextToken`   | string | 否   | 分页游标（来自上一次响应）             |
| `searchMode`  | string | 否   | `fulltext`（默认）或 `keyword`         |

```bash
curl -X POST http://192.168.30.68:13718/api/v1/knowledge/search \
  -H "Authorization: Bearer a9b5fcaf-f5e3-43a6-bb31-6dd4611560ac" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "如何申请年假",
    "operatorId": "abc123xyz",
    "maxResults": 10
  }'

```

跨 workspace 指定目录搜索：

```bash
curl -X POST http://192.168.30.68:13718/api/v1/knowledge/search \
  -H "Authorization: Bearer a9b5fcaf-f5e3-43a6-bb31-6dd4611560ac" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "绩效考核流程",
    "operatorId": "abc123xyz",
    "workspaceId": "ws_001",
    "directoryId": "dir_hr",
    "maxResults": 5,
    "searchMode": "keyword"
  }'

```

**响应**：

```json
{
  "items": [
    {
      "chunkId": 123,
      "documentId": 456,
      "title": "员工手册 2025",
      "chunkText": "年假申请需提前 3 个工作日...",
      "headingPath": "第三章 > 假期制度",
      "pageNo": 12,
      "score": 0.95,
      "sourceUrl": "https://alidocs.dingtalk.com/..."
    }
  ],
  "nextToken": "eyJvZmZzZXQiOjEwfQ==",
  "total": 42
}
```

### 2.2 获取上下文窗口

**POST** `/api/v1/knowledge/context`

获取目标 chunk 前后的相邻 chunk，用于为 LLM 提供更完整的上下文。

**字段说明**：

| 字段                     | 类型        | 必填   | 说明                        |
| ------------------------ | ----------- | ------ | --------------------------- |
| `chunkId`                | int64       | 二选一 | chunk ID                    |
| `documentId` + `chunkNo` | int64 + int | 二选一 | 文档 ID + chunk 序号        |
| `windowSize`             | int         | 否     | 前后各取 N 个 chunk，默认 2 |

方式一：通过 chunkId：

```bash
curl -X POST http://192.168.30.68:13718/api/v1/knowledge/context \
  -H "Authorization: Bearer a9b5fcaf-f5e3-43a6-bb31-6dd4611560ac" \
  -H "Content-Type: application/json" \
  -d '{
    "chunkId": 123,
    "windowSize": 3
  }'

```

方式二：通过 documentId + chunkNo：

```bash
curl -X POST http://192.168.30.68:13718/api/v1/knowledge/context \
  -H "Authorization: Bearer a9b5fcaf-f5e3-43a6-bb31-6dd4611560ac" \
  -H "Content-Type: application/json" \
  -d '{
    "documentId": 456,
    "chunkNo": 5,
    "windowSize": 2
  }'

```

**响应**：

```json
{
  "chunks": [
    {
      "chunkId": 121,
      "chunkNo": 3,
      "chunkText": "前文内容...",
      "headingPath": "第三章",
      "pageNo": 11,
      "isFocus": false
    },
    {
      "chunkId": 123,
      "chunkNo": 5,
      "chunkText": "目标 chunk 内容...",
      "isFocus": true
    },
    {
      "chunkId": 125,
      "chunkNo": 7,
      "chunkText": "后文内容...",
      "isFocus": false
    }
  ],
  "documentTitle": "员工手册 2025",
  "sourceUrl": "https://alidocs.dingtalk.com/..."
}
```

### 2.3 知识库问答

**POST** `/api/v1/knowledge/ask`

基于知识库检索结果进行 RAG 问答，支持多轮对话。检索链路沿用 `/api/v1/knowledge/search` 的 ACL 过滤逻辑，只会使用当前 `operatorId` 可访问的内容作答。

会话历史保存在服务端内存中，默认 30 分钟无活动过期。首次提问可不传 `sessionId`；若要继续同一轮对话，请在后续请求中带回上一次响应中的 `sessionId`。

**字段说明**：

| 字段         | 类型   | 必填 | 说明                                  |
| ------------ | ------ | ---- | ------------------------------------- |
| `question`   | string | 是   | 用户问题                              |
| `operatorId` | string | 是   | 操作者 unionId（用于 ACL 过滤和审计） |
| `sessionId`  | string | 否   | 会话 ID；不传则由服务端创建新会话     |
| `maxChunks`  | int    | 否   | 参与回答的检索片段数，默认 5，上限 20 |

首次提问（创建新会话）：

```bash
curl -X POST http://192.168.30.68:13718/api/v1/knowledge/ask \
  -H "Authorization: Bearer a9b5fcaf-f5e3-43a6-bb31-6dd4611560ac" \
  -H "Content-Type: application/json" \
  -d '{
    "question": "员工年假需要提前多久申请？",
    "operatorId": "abc123xyz",
    "maxChunks": 5
  }'

```

继续同一会话：

```bash
curl -X POST http://localhost:8080/api/v1/knowledge/ask \
  -H "Authorization: Bearer a9b5fcaf-f5e3-43a6-bb31-6dd4611560ac" \
  -H "Content-Type: application/json" \
  -d '{
    "question": "如果是调休呢？",
    "operatorId": "abc123xyz",
    "sessionId": "f5a8c7d1f2b34c6e9a0b1c2d3e4f5678"
  }'

```

**响应**：

```json
{
  "sessionId": "f5a8c7d1f2b34c6e9a0b1c2d3e4f5678",
  "answer": "根据《员工手册 2025》，年假申请需至少提前 3 个工作日提交审批。",
  "citations": [
    {
      "chunkId": 123,
      "documentId": 456,
      "documentTitle": "员工手册 2025",
      "sourceUrl": "https://alidocs.dingtalk.com/...",
      "headingPath": "第三章 > 假期制度"
    }
  ]
}
```

未检索到相关内容时，接口仍返回 HTTP 200，`answer` 为兜底提示，`citations` 为空数组。

常见错误：

- `400`：请求体不是合法 JSON，或缺少 `query` / `operatorId`
- `503`：LLM 未配置，返回 `{"error":"ask: LLM generator not configured"}`

## 3. 知识库摄取接口

### 3.1 扫描入库（异步）

**POST** `/api/v1/knowledge/scan`

接受钉钉文档或文件夹 URL，创建异步扫描任务并立即返回。Worker 自动完成扫描 → 入库 → 拉取 → 分块 → 向量化 → 写索引的完整流程。

**字段说明**：

| 字段         | 类型   | 必填 | 说明                                                       |
| ------------ | ------ | ---- | ---------------------------------------------------------- |
| `url`        | string | 是   | 钉钉文档或文件夹链接（必须为 `alidocs.dingtalk.com` 域名） |
| `operatorId` | string | 否   | 操作者 unionId                                             |
| `spaceId`    | string | 否   | 指定 space ID                                              |
| `maxDocs`    | int    | 否   | 最大文档数限制                                             |

扫描单个文档：

```bash
curl -X POST http://192.168.30.68:13718/api/v1/knowledge/scan \
  -H "Authorization: Bearer a9b5fcaf-f5e3-43a6-bb31-6dd4611560ac" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://alidocs.dingtalk.com/uni-preview?extension=pdf&bizType=document&watermark=true&cloudSpaceDentryId=182249118904&previewAtta=0&cloudSpaceSpaceId=713357598&version=1&scene=universalSpace&mainsiteOrigin=mainsite&spaceId=713357598&fileSize=5780935&dentryUuid=o14dA3GK8gGyy0pOU9BNZ19k89ekBD76&isMobile=false&fileId=182249118904 ",
    "operatorId": "abc123xyz"
  }'

```

扫描整个文件夹（限制 200 篇）：

```bash
curl -X POST http://192.168.30.68:13718/api/v1/knowledge/scan \
  -H "Authorization: Bearer a9b5fcaf-f5e3-43a6-bb31-6dd4611560ac" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://alidocs.dingtalk.com/i/nodes/folder\_xxx",
    "operatorId": "abc123xyz",
    "maxDocs": 200
  }'

```

**响应**（HTTP 202 Accepted）：

```json
{
  "taskId": 88,
  "status": "pending"
}
```

### 4.2 重试失败任务

**POST** `/api/v1/tasks/{id}/retry`

将状态为 `failed` 或 `dead` 的任务重置为 `pending`，触发重试。

```bash
curl -X POST http://192.168.30.68:13718/api/v1/tasks/88/retry \
  -H "Authorization: Bearer a9b5fcaf-f5e3-43a6-bb31-6dd4611560ac"

```

**响应**：

```json
{
  "taskId": 88,
  "status": "pending"
}
```

任务状态不为 `failed`/`dead` 时返回 HTTP 409：

```json
{ "error": "task is not in a retryable state" }
```

## 鉴权

配置 `API_KEYS` 环境变量后，所有非健康检查接口都需要在请求头携带：

```plaintext
Authorization: Bearer <key>

```

`/healthz` 和 `/readyz` 始终放行，无需鉴权。

每个请求会自动生成或透传 `X-Request-ID` 用于日志追踪：

```bash
curl http://192.168.30.68:13718/api/v1/tasks/88 \
  -H "Authorization: Bearer a9b5fcaf-f5e3-43a6-bb31-6dd4611560ac" \
  -H "X-Request-ID: my-trace-id-001"

```

测试环境 key `a9b5fcaf-f5e3-43a6-bb31-6dd4611560ac`
